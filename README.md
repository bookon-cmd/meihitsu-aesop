# 名筆（MEIHITSU）第2弾：イソップ寓話集 珠玉の名作50選

パブリックドメインの名文を**「朗読音声で味わう」**ことを中心に設計されたWebアプリケーション「名筆」シリーズの第2弾です。

世界中で愛されるイソップの有名寓話から、誰もが知る**珠玉の名作50話**を完全収録しています。

---

## 主な機能・特徴

1. **画面の主役は大きな再生ボタン**
   - 1タップですぐに朗読がスタート。スペースキーでの再生/一時停止にも対応。
2. **いつでも見渡せる「作品目録（インデックス・ドロワー）」搭載**
   - 画面上部および下部の「目録」ボタンから、全50話の日本語題・英題・教訓一覧をいつでもスライド展開。
   - インクリメンタル検索（キーワード・番号）、再生中ハイライト、タップで即ジャンプ。
3. **「今日の一話」を自動選定**
   - アクセスした日付に合わせて毎日1話が選ばれます（同日は何度アクセスしても同じ話を表示）。
4. **連続再生（ラジオのように流し聴き）**
   - 1話が終わると自動で次の作品へ進みます（「順番どおり」「シャッフル」「オフ」）。
5. **音声エンジン ＆ リアルタイム行ハイライト**
   - ブラウザ標準の英語音声合成（SpeechSynthesis）で1文ずつ黄金色にハイライトしながら自然に読み上げ。
6. **全50話の原文 ＆ オリジナル現代日本語「ざっくり訳」**
   - V.S. Vernon Jones版の英文テキスト（全265文）。
   - 1文ごとに意味が掴める平易で美しい現代日本語のオリジナル訳を書き下ろし。
   - 結びの「教訓（モラル）」を特別なゴールドカードで強調。
   - 和訳表示3段階（「非表示」「タップした文だけ表示」「すべて表示」、localStorage保存）。
7. **細やかな再生コントロール**
   - 速度切替（`0.75x` / `1.0x` / `1.25x`）
   - スリープタイマー（`15分` / `30分` / `オフ`、残り秒数カウントダウン付き）
   - Media Session API完全対応（スマホのロック画面やイヤホンボタンで操作可能）
